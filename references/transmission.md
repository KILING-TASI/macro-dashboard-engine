# 宏观因子 → 股市传导方法论

本文档定义看板「传导与资产映射」区的分析框架：从宏观因子出发，经中间变量，传导至股票市场（估值/盈利/流动性/风格/行业）。

---

## 一、总览：三条主传导路径

宏观因子影响股市，本质通过三条渠道：

```
                    ┌──────────────────────────────┐
   宏观因子  ──────► │  ① 盈利端（分子 E）           │ ──► 企业盈利 → 顺周期/周期股
   (货币/信用/       │  ② 估值端（分母：无风险利率/   │ ──► 估值扩张/收缩 → 成长/价值
    通胀/汇率/海外)  │     风险偏好）                 │
                    │  ③ 流动性端（增量资金）        │ ──► 外资/杠杆资金 → 大盘/小盘
                    └──────────────────────────────┘
```

---

## 二、五条标准传导链（看板 graph 图数据）

每条链 = `因子 → 中间变量 → 股市影响`，用于看板传导链路图渲染。

### 链 1：货币宽松链
```
货币政策宽松 → 利率↓ → 贴现率↓ → 估值(分母)↓ → 估值扩张 → 成长股/科技占优
```

### 链 2：信用扩张链
```
社融增速↑ / 宽信用 → 企业中长贷↑ → 实体需求回暖 → 盈利↑ → 顺周期/银行/周期股受益
```

### 链 3：通胀链
```
CPI/PPI↑ → 上游涨价 → 上游周期品盈利↑（利好资源/能源）
            └→ 中下游成本↑ → 中游制造/消费利润受压（利空）
```

### 链 4：汇率链
```
人民币贬值 → 外资流出压力↑ → 北向资金↓ → 大盘蓝筹承压
              └→ 出口链受益（出口占比高的行业）
```

### 链 5：海外流动性链
```
美联储加息 → 美债收益率↑ → 全球风险偏好↓ → 新兴市场(含A股)估值承压
美联储降息 → 美债收益率↓ → 美元↓ → 新兴市场资金回流 → 利好A股
```

## 四、配置建议生成规则

配置建议由 **周期象限** 驱动（见 `cycle_framework.md`）：

| 象限 | 风格建议 | 板块建议 | 逻辑要点 |
|---|---|---|---|
| 复苏 | 成长 > 价值 | 科技、消费 | 增长回暖+通胀低，估值扩张+盈利改善双击 |
| 过热 | 周期 > 成长 | 有色、能源、化工 | 通胀上行，上游资源盈利弹性大 |
| 滞胀 | 防御 > 周期 | 公用事业、必需消费 | 增长下行+通胀高，杀估值，避险为主 |
| 衰退 | 价值/高股息 | 银行、高股息 | 增长通胀双降，利率下行，稳健资产占优 |

**叠加修正**：
- 若信用周期为「宽信用」→ 顺周期/金融板块权重上调
- 若人民币贬值压力大 → 下调外资敏感板块（大盘蓝筹），上调出口链
- 若美债利率上行 → 下调成长板块（对贴现率敏感）
