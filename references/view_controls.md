# 已载入看板的显示交互与留档

更新日期：2026-10-09。PR #1 待审；显示逻辑及留档格式为 1.0.0，计算方法仍是 2.0.0，不新增预测或周期模型。

## 实际范围

- 关键词、来源及状态筛选作用于证据表、信用明细和缺口；主指标和周期结论保留原值。取得输入与核验原文分开，教学不冒充真实输入。
- 时间窗口有全部、最近 12/36 个月和自定义月份，只改变日期图表显示。锚点为已载入日期图表最新月，不是假装当前联网时间。缺期/空值不插值、不重采样；季度标签按季首月匹配范围，标签和数值保留原样。
- 无观测窗口有明确遮罩；日期错误时保留上次有效显示。重置恢复全部窗口和筛选，不清除图例选择。
- 排序仅使用已有增长贡献和原报告已算的尺度敏感性。表格列原分数及相对 1 倍尺度的偏移，缺基准或分数时偏移未知。不应用假设、不切换主结论、不跨月/季覆盖数量排名。
- 表格显示 4 位小数，导出保留原精度。不写回 HTML、旧归档或原始响应，无在线刷新或交易。

## 导出格式

先“应用显示参数”，再“生成留档参数”，可查看 JSON 并下载新文件。未应用或非法输入不替换上次有效参数。文件名带 UTC 时间，最终下载位置由浏览器设置决定。

`schema_version=macro-view-1.0.0`：

| 字段 | 含义 |
|---|---|
| `controls_version`、`method_version` | 显示逻辑和原报告方法版本；方法未登记为 null |
| `saved_at`、`report_generated_at` | 另存时间（ISO UTC）及原报告生成时间；原报告未记录时区，`report_timezone=null` |
| `data_mode`、`data_status` | formal/teaching 及原完整/部分/教学状态，不冒充刷新 |
| `parameters`、`resolved_window`、`window_anchor` | 已应用的筛选、窗口、排序及解析范围 |
| `chart_views` | 原图实际缩放及图例；无观测为 false，缩放留空 |
| `display_payload` | 完整已载入展示快照，含日期、空值、来源和已有计算；不是原始响应 |
| `display_payload_sha256` | 浏览器 JSON.stringify 展示快照的 UTF-8 SHA256，不是原文件/官方原文认证；浏览器不支持时为 null，仍可导出 |

未实现留档回读后自动恢复、重建原始响应或按窗口重算模型，不能由“可导出”推断。公开再分发留档仍需按[许可范围](../LICENSE_SCOPE.md)核对数据权限。

已有真实归档本地验收：55 项证据/缺口筛出 4 项商务部来源的滞后信用数据，原生时间轴窗口与所选月份一致；筛选前后展示快照哈希一致。未重新采集外部数据，不证明接口持续可用或全部原文核验。
