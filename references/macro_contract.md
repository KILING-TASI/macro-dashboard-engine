# 宏观工具与工作台边界（契约1.0.0）

本包保持独立。可选导出器仅传递7项国内指标及美国CPI的已取得序列、增长/通胀/库存/信用观察；无research-workbench依赖。旧取数、计算和HTML入口保留，不复制整套看板或修改工作台代码。

| 层 | 接口交付 | 工作台职责与未等价范围 |
|---|---|---|
| 官方原始观测 | 已取得的原文URL、发布日期、定位与核验记录，未知保持未知 | 官方发布解读需要原文核验，不能用聚合序列直接替代 |
| 聚合序列 | 东方财富/FRED原日期、精度、空值、单位及输入元数据 | 工作台CPIAUCSL同比、DFF有效利率、资产共同日期窗口与原始响应逐点复解析有独立口径，未实现等价转换 |
| 周期解释 | 有限周期观察、贡献与敏感性，不含资产配置、回归或长周期 | 工作台负责研究问题、竞争解释、核验与报告，不把评分当官方事实或实时预测 |

## 接口

`scripts/macro_contract.py`的`export_bundle(sources)`接收现有eastmoney/fred载荷；`restore_sources(bundle)`还原所选指标和上下文。不映射工作台内部指标ID。

- `contract_version=1.0.0`约束格式，未知格式拒绝还原；`calculation_version=2.1.0`约束计算含义，不与旧增长评分混用。
- `observations[].payload`保留原字段，不舍入、不补值、不变单位。缺频率时GDP用Q，其他选定指标用M，标记`catalog_assumption`。
- 保留观测期、获取时间、发布与修订时点、来源和证据状态。未取得时点为null，不用观测期替代。`input_context`保存原上下文；`evidence`区分生产机构和获取渠道。
- `gaps`列未取得指标；`missing_dates`列显式全空观测，未提供月份由原日期识别，不插入人工行。CLI保留输入和代码SHA256，哈希不证明来源认证。
- 教学输入标`kind=teaching`；`point_in_time=false`表示逐期首次发布与修订版本尚未取得。没有费用字段，不添加费用假设。

## 计算2.1.0的明确变更

日期和值长度一致、升序且不重复；末端空值或缺期截断窗口。M按相邻月，Q按相邻季；D按工作日，仅容许周末，不推定节假日；W按7天。D未配官方日历，节假日会保守缩短窗口。趋势至少4个连续有效原生观测；通常月度3/12窗口、GDP用2/至多8季；不足时缩短窗口并披露数量。水平判断不冒充趋势。

增长：PMI原有有界分数除以1.2，社零趋势tanh(百分点/2)，GDP趋势tanh(百分点/1)，统一到[-1,1]、可用维度等权。输出raw/scale/transform/score/weight/contribution，提供尺度减半/加倍和删维度敏感性。参数为研究假设；与旧评分不同是有意版本变更，不宣称旧新等价。

回归拒绝尾部错位，日频按升序真实观测取月末最后有效值；仅相邻月差分。缺发布与修订时点只作事后历史关联。

## 复现与保存

教学输入`references/examples/contract-input.json`；`tests/test_macro_contract.py`验证往返精度、日期、空值、未知时点一致，并与同版本直接周期计算对照。

```text
python scripts/macro_contract.py --eastmoney <归档em.json> --fred <归档fred.json> --out <新文件.json>
python -m unittest discover -s tests
```

导出器拒绝覆盖既有文件。流水线在--workdir父目录另建run目录，不清除旧档案；子任务先写同目录临时文件，成功且非空后发布。HTML默认另存，显式--overwrite仅在成功后原子替换；失败保留旧文件，本轮不读取旧目录冒充新结果。

本批仅契约、导出器及转换样本，没有迁移/删除工作台功能，没有跨包等价验收。官方原文采集、资产价格/总收益、工作台注册表、逐期发布时间和原始响应逐点复解析均未替代。


当前版本的日历同比、频率校验、默认保留原值与可选屏蔽详见[方法卡](macro_method_cards.md)。历史截图与冻结归档按各自记录版本解释，不自动更新。
