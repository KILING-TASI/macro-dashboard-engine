# 长周期（长波梯队）方法论

本文件说明 macrodashboard 中「长周期梯队」模块的计算口径与使用边界。

---

## 一、为什么要把长周期单列一层？

经典宏观周期分析（美林时钟、库存周期、信用周期）时间尺度在 **3 个月 ~ 4 年**，回答的是「未来 1-2 个季度配置什么」。但资产价格的中长期底部/顶部，往往由更长尺度的周期决定：

| 周期 | 长度 | 主导变量 | 投资含义 |
|---|---|---|---|
| 基钦（库存） | 3-4 年 | 库存/需求 | 短周期择时 |
| **朱格拉（设备投资）** | **7-11 年** | 企业资本开支 | 制造业/周期股轮动 |
| **库兹涅茨（地产）** | **15-25 年** | 住宅投资/房价 | 地产链、银行、大宗长期格局 |
| **债务周期（Dalio）** | **50-75 年** | 债务/GDP | 大类资产长期β |
| **康波（Kondratiev）** | **50-60 年** | 技术革命集群 | 战略级主题 |

> **原则**：能数据驱动的老实算（朱格拉、库兹涅茨、债务代理），算不了的（康波、熊彼特）用定性框架并**明确标注**，绝不硬造数据结论。

## 二、数据驱动部分

### 2.1 计算流程

```
原始序列(季/月/周)
  → 统一重采样为季度（每季取最后有效值）
  → z-score 标准化（消除量纲）
  → 去超长趋势（减去 2×长窗移动平均）
  → 带通滤波：band(t) = MA(short)(x) - MA(long)(x)
  → 再标准化 + ±3σ 截断（去尖刺）
  → 水平(z) + 方向(4期斜率) 融合 → 阶段判定
  → 局部极值识别 → 历史峰谷（含最小跨度约束）
```

**带通滤波说明**：`MA(short) - MA(long)` 是 BK/CF 滤波的简化实现，能提取「短于 long 窗、长于 short 窗」的频段分量，无需 scipy 依赖。

### 2.2 三个周期的参数

| 周期 | 合成输入 | 带通窗口 | 理论周期 |
|---|---|---|---|
| **朱格拉** | 设备投资同比 + 私人固投同比 | `MA(20Q) - MA(48Q)` | 7-11 年 |
| **库兹涅茨** | 住宅投资同比 + 新屋开工 + 房价同比 | `MA(40Q) - MA(100Q)` | 15-25 年 |
| **债务** | 债务/GDP 的**同比变化(Δ)** + 银行信贷脉冲 | 直接 z-score | 长债代理 |

> ⚠️ 债务周期必须用**变化率**而非水平值。债务/GDP 长期单调上升，用水平值做 z-score 会永远输出「高位」，无判别力。

### 2.3 阶段判定规则

用「水平 z + 4 期斜率方向」融合：

| 水平 z | 方向 | 阶段 |
|---|---|---|
| ≥ 0.6 | ≤ 0 | 周期见顶 |
| ≥ 0.6 | > 0 | 高位扩张末段 |
| 0 ~ 0.6 | > 0 | 扩张中段 |
| 0 ~ 0.6 | ≤ 0 | 扩张转弱 |
| < 0 | ≤ 0 | 收缩/筑底中 |
| < 0 | > 0 | 底部回升 |

### 2.4 已验证的历史准确度

**朱格拉周期**（1948Q1 起，314 个季度）：

- 峰：1957Q3 / 1964Q2 / 1977Q3 / 1986Q1 / 1996Q2 / 2005Q3 / 2012Q3 / 2023Q4
- 谷：1959Q1 / 1969Q1 / 1973Q2 / 1981Q1 / **1989Q2** / **2001Q1** / **2007Q4** / 2018Q1

平均跨度约 8 年，落在 7-11 年理论区间内。谷底 1989Q2（储贷危机）、2001Q1（互联网泡沫）、2007Q4（次贷危机）与真实设备投资周期高度吻合。

**库兹涅茨周期**（1987Q4 起，155 个季度）：

- 谷：**1990Q2**（储贷地产危机）/ 1993Q4 / 2007Q2 / **2011Q3**（次贷后地产出清）/ **2024Q3**

**债务周期**（1967Q1 起，237 个季度）：

- 谷（去杠杆最深）：1969Q3 / 1973Q4 / 1979Q1（大通胀去杠杆）/ 2021Q2（疫情）/ 2023Q1

## 三、定性框架部分（康波 / 熊彼特）

### 3.1 为什么不能数据驱动？

康波周期描述的是**技术革命集群的扩散与出清**，50-60 年一轮。全球范围内：

- 无被广泛认可的量化序列（专利数、TFP 等代理都争议巨大）
- 即使是 1919 年起的美国工业生产指数（FRED `INDPRO`），100 年历史也仅覆盖约 1.7 轮，样本不足以统计识别
- 硬算出来的「康波」不可复现、不可验证

因此本模块采用**技术革命浪潮时间轴 + 结构特征匹配**的定性方法。

### 3.2 六次技术革命浪潮

| 浪次 | 名称 | 核心技术 | 时间 | 主导国 |
|---|---|---|---|---|
| 1 | 纺织与蒸汽 | 蒸汽机、纺织机械、铁 | 1780-1840 | 英国 |
| 2 | 钢铁与铁路 | 钢铁、铁路、轮船 | 1840-1890 | 英/德 |
| 3 | 电气与重化工 | 电力、内燃机、化工 | 1890-1950 | 德/美 |
| 4 | 汽车与石化 | 汽车、石化、电子 | 1950-1990 | 美/日 |
| 5 | 信息技术 | 计算机、互联网、移动通信 | 1990-2020 | 美/中 |
| 6 | AI 与新能源 | AI、光伏储能、生物、量子 | 2020-2060 | 美/中 |

### 3.3 当前定位

**第五浪（信息技术）下半程 → 衰退/萧条过渡；第六浪（AI/新能源）孕育中**

支持特征：

- 全要素生产率增速自 2005 年后系统性放缓
- 全球债务/GDP 处历史高位，信用扩张空间受限
- AI 大模型、新能源、生物技术在 2020 年代集中突破

### 3.4 使用边界

> 长波周期时间尺度 50-60 年，对 1-3 年投资决策的指导意义有限，**适合作为战略背景板，不适合择时**。看板中所有康波/熊彼特相关结论均标注「定性判断」，与数据驱动的朱格拉/库兹涅茨严格区分显示。

## 四、与其他模块的关系

- **美林时钟 / 库存 / 信用周期**：战术层（1-2 季度），决定仓位与行业轮动
- **朱格拉 / 库兹涅茨**：战略层（3-10 年），决定中期产业配置偏向
- **债务 / 康波**：终极背景层（50 年+），决定大类资产长期β与主题方向

三层叠加形成「长中短」共振视角：当短周期（库存）与中周期（朱格拉）共振向上时，配置胜率最高；当长周期（康波）处于萧条期时，需对中期乐观信号保持警惕。
